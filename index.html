Konversi & kecepatan

Ubah format (misalnya video ke MP3) atau percepat dan perlambat audio/video. Diproses di perangkat Anda dan langsung diunduh.

Library

Jelajahi file audio, video, dan gambar di perangkat Anda. File tidak diunggah ke mana pun dan hanya dibaca saat Anda memilihnya.

Cara pakai

  1. Buka Google Colab, jalankan backend MAB-Music Vokal sampai muncul alamat HTTPS.
  2. Salin alamat itu, tempel di kolom URL API Backend di pojok atas, lalu tekan Tes koneksi.
  3. Titik berubah hijau? Berarti siap. Isi gaya musik dan lirik, atur durasi, lalu tekan Generate Music.
  4. Tunggu sampai lagu selesai (1 menit lagu bisa butuh beberapa menit, lagu panjang lebih lama). Jangan tutup tab Colab.
  5. Lagu muncul di pemutar dan bisa diunduh sebagai .mp3.

Alamat Colab berubah setiap kali dinyalakan ulang, jadi tempel yang baru. Alamat terakhir diingat browser ini.
