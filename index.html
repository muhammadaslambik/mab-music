Cara pakai

  1. Buka Google Colab, jalankan backend MAB-Music sampai muncul alamat HTTPS.
  2. Salin alamat itu, tempel di kolom URL API Backend di pojok atas, lalu tekan Tes koneksi.
  3. Titik berubah hijau? Berarti siap. Tulis deskripsi musik dan tekan Generate Music.
  4. Tunggu sekitar 20 detik sampai 2 menit. Lagu muncul di pemutar dan bisa diunduh.

Alamat Colab berubah setiap kali dinyalakan ulang, jadi tempel yang baru. Alamat terakhir diingat browser ini.
